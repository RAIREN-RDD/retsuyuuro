# Retsuyuuro / 裂融炉 | Structured decomposition. Deterministic synthesis.
A C++ framework for creating webservers and websites with ease and safety with precision.

## ❖ Prerequisites
- A compiler supporting C++23
- Make

## ❖ Static libraries
- OpenSSL 3.5.7
- libpq
- libpqxx
- libsodium
- uWebSockets
- Redis (integration soon)
